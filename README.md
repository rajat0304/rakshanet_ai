# RakshaNet Website Prototype

A self-contained, offline-friendly prototype based on the RakshaNet proposal UI:
- Live Monitoring Dashboard
- Live Traffic
- Alerts
- File Vault
- Active Incident / Containment
- Forensics
- Post-Attack Report
- Settings

## Run
Just open `index.html` in a browser.

## Demo
1. Start on Dashboard.
2. Click **Simulate Attack**.
3. Watch the UI move to the active incident page.
4. Click **Generate Report**.
5. Use the sidebar to explore Vault, Alerts, Forensics and Reports.

This is a front-end demo with simulated telemetry and attack states; it does not perform real intrusion detection or encryption.
